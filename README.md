## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/tanush090/tanush-portfolio-26.git
cd tanush-portfolio-26
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

### 4. Create a production build

```bash
npm run build
```

Run these commands from the repository root. The scripts must exist in `package.json`; adjust them if your project uses different commands.
